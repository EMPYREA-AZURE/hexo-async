一、准备工作

1. 获取服务器信息

  • 服务器IP：在阿里云控制台的轻量应用服务器详情页找到公网IP地址（如 123.123.123.123）。
  • 宝塔面板登录信息：在服务器详情页的“应用详情”中查看初始账号（默认用户名 admin）和密码。

2. 本地Hexo项目准备

  • 确保本地已生成Hexo静态文件：

  • 静态文件位于本地Hexo项目的 public 文件夹内。

二、宝塔面板初始化

1. 登录宝塔面板

  • 浏览器访问 http://服务器IP:8888（如 http://123.123.123.123:8888）。
  • 输入初始账号密码登录（首次登录需同意用户协议）。

2. 安装基础环境

  • 登录后，宝塔会自动弹出环境安装窗口：
    • 选择LNMP环境：仅勾选 Nginx 1.24（Hexo无需PHP和MySQL）。
    • 安装方式：选择“极速安装”（速度更快）。
    • 点击“一键安装”并等待完成（约5-10分钟）。

三、部署Hexo网站

1. 创建网站站点

  • 进入宝塔面板 → 网站 → 添加站点：
    • 域名：填写你的阿里云域名（如 example.com），若未备案可暂时填服务器IP。
    • 根目录：默认 /www/wwwroot/hexo（可自定义，如 /www/wwwroot/your-site）。
    • 其他选项保持默认，点击“提交”。

2. 上传Hexo静态文件

  • 方法一：宝塔文件管理器上传

    1. 进入宝塔面板 → 文件 → 定位到站点根目录（如 /www/wwwroot/hexo）。
    2. 删除默认的 index.html，点击“上传” → 选择本地Hexo的 public 文件夹内所有文件。
    3. 等待上传完成。

  • 方法二：SSH远程上传（可选）

    bash

3. 访问测试

  • 浏览器访问 http://服务器IP 或 http://你的域名，即可看到Hexo网站。

四、域名解析与备案

1. 域名解析（阿里云控制台）

  • 进入阿里云域名控制台 → 找到你的域名 → 解析设置：
    • 添加记录：类型A → 主机记录@ → 记录值=服务器IP → 保存。
  • 解析生效时间约10分钟~24小时。

2. 备案须知

  • 若服务器位于中国大陆（如华南3-广州），必须完成域名备案才能通过域名访问。
  • 备案流程需10-20天，期间可通过服务器IP测试网站。

五、安全优化

1. 修改宝塔面板默认设置

  • 修改面板端口：进入面板 → 面板设置 → 修改端口（如 8888 → 5555）。
  • 修改面板密码：同上 → 设置复杂密码。
  • 关闭测试页面：删除宝塔自动生成的 www/wwwroot/hexo 下的默认文件。

2. 防火墙配置

  • 确保阿里云轻量应用服务器的防火墙（安全组）开放以下端口：
    • 80（HTTP）、443（HTTPS）、22（SSH）、宝塔面板端口（如5555）。

3. HTTPS证书申请（可选）

  • 进入宝塔面板 → 网站 → 选择站点 → SSL → 申请Let’s Encrypt免费证书 → 强制HTTPS。

六、未来扩展多站点

1. 添加新站点

  • 重复 第三部分第1步，为每个新站点分配独立域名和根目录（如 /www/wwwroot/site2）。

2. 资源优化

  • 静态资源托管：将图片、视频等大文件迁移至阿里云OSS，通过CDN加速。
  • 定期备份：宝塔面板 → 计划任务 → 设置网站文件和数据库自动备份。

七、常见问题解决

1. 访问网站显示403错误

  • 原因：文件权限不足或根目录路径错误。
  • 解决：
    • 检查宝塔站点设置的根目录是否与上传文件路径一致。
    • 在宝塔文件管理器中，将站点目录权限设置为 755，文件权限 644。

2. 宝塔面板无法访问

  • 原因：防火墙未开放端口或IP被限制。
  • 解决：
    • 检查阿里云安全组是否放行宝塔面板端口。
    • 在宝面板 → 安全 → 检查IP限制规则。

八、最终验证

完成所有步骤后，你的Hexo网站应可通过以下方式访问：

  • IP临时访问：http://服务器IP
  • 域名正式访问：http://你的域名（需备案完成后生效）

如果有任何问题，可参考宝塔官方文档或阿里云轻量应用服务器帮助中心（如网页1、2、5的示例）。
